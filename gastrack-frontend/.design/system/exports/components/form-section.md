# Form Section

## Anatomy

1. Section title: 16px semibold
2. Section description: 13px muted-foreground (optional)
3. Fields: stacked with 12px gap
4. Divider below (optional)

## Layout

```
space-y-3
```

## Label

13px medium, text-foreground, 4px margin-bottom from field.

## Error Message

12px, text-destructive, 4px margin-top from field.

## Rules

- Labels above fields for forms wider than 400px
- Inline labels (left) for compact settings forms
- 12px gap between fields, 16px between sections
- Required fields: append `*` to label
